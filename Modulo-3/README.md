# Módulo 3 - SQL Server

## Preentrega 3: TechStore

Creación de una base de datos relacional para la gestión de ventas de una tienda de tecnología

El script incluye:
- Creación de la base de datos Ventas_Tech_DB
- Cuatro tablas: categorias, clientes, productos y ventas
- Definición de claves primarias y foráneas
- Carga de 25 registros
- Consultas de validación

Herramienta utilizada: SQL Server Management Studio (SSMS)
